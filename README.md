# 🚀 Low Level Design (LLD) Learning Journey

I have started learning **Low Level Design (LLD)** to improve my software engineering and system design skills.

This repository contains my learning notes, concepts, practice problems, and implementations as I explore object-oriented design and real-world system design.

## 📚 Topics I’m Learning

* Object-Oriented Programming (OOP)
* SOLID Principles
* Design Patterns
* UML Diagrams
* Class Diagrams
* Relationships between Objects
* Encapsulation, Abstraction, Inheritance & Polymorphism
* Low Level System Design
* Real-world Design Problems

My goal is to learn how to design **scalable, maintainable, and extensible software systems** by applying OOP principles, SOLID principles, and design patterns.

I’ll keep updating this repository as I continue my LLD journey.
